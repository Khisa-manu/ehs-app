Android Mobile Application (FieldPulse EHS)

Native Kotlin/Jetpack Compose Android app built for field technicians.

Android Studio Ready
FieldPulse Android Client v1.0.0

The Android application is located in the /android folder. It features:

  • Zero Network Dependency: Full offline clock-in with Room SQLite.
  • CameraX Photo Capture: High-resolution PPE, vehicle 360, and hazard photos.
  • Tamper Proofing: Monotonic hardware uptime validation and GPS mock prevention.
  • WorkManager Background Sync: Automatic upload when WiFi/Cellular restores.
Build APK in Android Studio:
1. Open the /android folder in Android Studio 2. Click Build > Build Bundle(s) / APK(s) > Build APK(s) 3. Deploy to phone via USB Debugging or Emulator
